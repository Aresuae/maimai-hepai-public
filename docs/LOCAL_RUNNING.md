# 本机持续运行、个人授权与 SQLite

外地朋友访问请使用新增的独立分享入口，见 [REMOTE_SHARING.md](REMOTE_SHARING.md)。不要直接把本文的 5173 开发服务器暴露到公网；分享脚本提供隔离的访客数据库和授权。

更新：2026-10-22。本模式是一台电脑的个人工作区；另外启动远程分享后，朋友可通过邀请链接或二维码加入共享餐桌。尚未实现正式用户注册和跨设备身份找回。

## 一直运行

需要 Node.js 22.13+，已验证 Node.js 24.18.0。在项目目录执行：

```powershell
# 在项目根目录执行
npm.cmd run local:keepalive
```

Windows 也可以双击 `本机持续运行.cmd`，访问 http://127.0.0.1:5173/。

- 保持终端窗口运行、电脑开机及网络可用；休眠会暂停，关机会停止。Ctrl+C 退出。
- 异常退出 5 秒后重启，两分钟内连续失败 5 次后停止。端口已占用时不重复启动或自动换端口。
- 这是带重启守护的本机开发运行方式，不是 Windows 服务。没有修改休眠、防火墙、端口映射或开机启动项。退出 Codex 后不保证其启动的进程继续运行；长期使用请自行从上述终端或脚本启动。
- 本机入口只绑定 127.0.0.1，其他电脑和手机不能直接访问这个本机地址。请同时双击 `远程分享启动.cmd`，等待网页生成公网邀请链接和二维码，再发给朋友；不要求朋友与你处在同一个 Wi-Fi。
- `npm run build` 保持 Worker 构建；`npm start` 仍为该构建的本地预览，不提供本轮 Node SQLite 和账号接口。

## 连接自己的麦当劳账号

首页右上角 → **我的账号**（未连接时为“账号登录”）→ 弹窗。

1. 已在 `.env.local` 配置 Token：点击 **验证并保存已有授权**。
2. 新连接或更换账号：点击 **去官方平台登录**，在 https://open.mcd.cn/mcp 用自己的手机号登录，再从官方控制台获取 MCP Token。手机号、验证码和协议均在官方页面处理。
3. 将 Token 粘贴到本机网页，点击 **验证并连接账号**。提交后输入框清空，官方只读查询成功后才替换现有连接。
4. 成功后显示验证时间，Token 加密保存；不回显原文，不返回账号手机号或凭空显示会员有效期。
5. 更换、重新验证或断开会增加授权版本并重置真实餐单。旧页面请求、切换前仍在运行的查询结果会被服务端拒绝；其他同源页面通过通知或轮询更新。
6. **断开本应用连接** 会删除当前数据库授权并持久化禁用环境配置回退。不会撤销官方 Token 或修改 `.env.local`；重新连接需重新粘贴验证。

[官方文档](https://github.com/M-China/mcd-mcp-server)核实了手机号登录开放平台后获取个人 Token 的流程，尚未核实可嵌入第三方应用的 OAuth/扫码登录。本功能是个人授权连接，不是官方原生登录，也不是麦麦合拍多人账号。只验证和查询，不会自动领券、建单或支付。

## 数据库与迁移

本机工作区数据库：`data/maimai.sqlite`，WAL 模式，schema version 1。

| 表 | 内容 |
| --- | --- |
| local_account | 单个本机所有者的加密 Token、授权版本、成功验证时间与断开状态 |
| gatherings | 找搭子发布，包括日期、人数、预算与招募状态 |
| collections | 发布集合版本，用于事务内拒绝过时写入 |

原浏览器发布在初次读取时导入，按 ID 去重，数据库记录优先；原浏览器记录保留作备份。损坏数据不覆盖数据库。多个本机页面共用同一工作区，不代表真实用户之间已经实现权限隔离。

服务端重新校验发布字段、未来时间和状态；事务内比较 revision，冲突时拒绝覆盖。验证 Token 后提交时同样检查授权版本，防止迟到验证覆盖已断开的连接。

共享餐桌另存于 `data/shared-tables.sqlite`，订单记录另存于 `data/checkouts.sqlite`；访客工作区保存于 `data/share/workspaces/`。固定饭搭子模板仍在浏览器；未保存的选餐草稿、演示投票和小票不属于共享数据库，真实报名尚未实现。

## 保管与恢复

`data/credential.key` 是随机密钥；数据库中的 Token 使用 AES-256-GCM 加密。密钥和数据库位于同一电脑，不能防御已能读取整个工作目录的人。请保护 Windows 账户与数据文件夹，不把整个 `data/` 发给别人；该目录及 `.env.local` 均被 Git 忽略。

备份时先停止程序，再复制完整 `data/` 到自己的受保护位置。恢复前停止程序并另存现有目录备份。单独复制运行中的主数据库可能遗漏 WAL 数据，恢复时遗漏密钥则无法解密授权。

密钥缺失不会自动生成新密钥并覆盖旧授权。可先断开连接，再粘贴官方 Token 重新验证，饭局记录会保留。没有上传任何数据备份。
