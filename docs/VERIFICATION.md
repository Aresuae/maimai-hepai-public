## 页面与只读联调

- 读取真实门店菜单，展示官方商品图片、套餐默认搭配及官方分类；分类内搜索可用。曾检查桌面及 390px 宽度布局。
- 在独立测试桌验证跨设备入口的昵称、预算、选餐与选好状态同步，刷新后可恢复当前浏览器身份；邀请链接及二维码进入同一桌。
- 验证二维码编码内容与完整邀请一致；二维码、临时域名及访问凭证不纳入公开截图。
- 验证断线重连后重新生成邀请入口。免费通道曾出现加载延迟和连接超时，不能保证长期或不同地区稳定可达。
- 验证过期饭局可以取消；关闭餐桌顶部显示重新开启入口，每次要求选择人数；成员卡片显示移出入口和确认信息。
- 单独的测试桌中，一人已选好、两人仍在选择，可以只导入已选好者的一份套餐并取得官方只读报价。菜单读取曾短暂失败，重试后恢复。
- 当前截图：[共享成员管理与分批结算](images/shared-table-demo.jpg)。使用测试昵称，不包含真实订单、账号或有效邀请。

## 没有验证或尚未实现

- 本轮浏览器验收没有点击真实“确认下单”、执行付款或核销；建单状态机使用模拟依赖测试。不得将只读核价成功描述为完整实单支付成功。
- 没有覆盖各地区、实体手机、微信内置浏览器、长期连续运行和大规模并发。
- 尚无正式用户注册、跨设备身份找回、嵌入式微信/麦当劳扫码授权、公开搭子市场或真实聊天。
- 美团/抖音团购券核销、自动买卡、任意套餐替换、自动最优优惠规划尚未实现。
- 已提交餐品在原桌不能再次修改；无订单号的未知建单结果暂无自动对账与解除阻塞界面。

## 发布与复现

运行 `npm run github:export` 生成源码目录、ZIP 和 SHA-256 文件清单。打包采用目录白名单、运行文件排除与文本凭证检查，包含文档测试截图和必要隐藏配置，不包含 node_modules、构建产物、数据库及密钥。

打包脚本不会修改业务数据、启动公网通道或上传仓库。详细上传及检查命令见 [GitHub 上传指南](GITHUB_UPLOAD.md)。

已独立解压读取 ZIP 的全部文件，并逐项核对文件清单中的 SHA-256；压缩包包含构建所需的隐藏配置、MCP 配置示例和第三方许可证。
