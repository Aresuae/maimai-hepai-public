# 公开参赛版本

公开仓库：[Aresuae/maimai-hepai-public](https://github.com/Aresuae/maimai-hepai-public)。

此版本基于当前「麦麦合拍」源代码整理，保留真实 MCP 接入、共享餐桌、成员管理、分批结算与演示功能。公开仓库使用独立 Git 历史，不复制私有开发仓库的旧提交。它是可下载运行的源码仓库，不是已经部署的在线点餐网站。

## 下载与运行

准备 Node.js 24 和 Git，在准备存放项目的目录运行：

```bash
git clone https://github.com/Aresuae/maimai-hepai-public.git
cd maimai-hepai-public
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`。Windows PowerShell 如阻止 `npm.ps1`，将命令中的 `npm` 换为 `npm.cmd`。

## 不连接个人账户也能体验

1. 在首页选择「合拍演示」。
2. 使用预置的虚构成员，或调整为 2—6 人，分别设置预算与偏好。
3. 选择示例主食、饮品和小食，可体验「随便」和「我请客」。
4. 生成演示方案、进行匿名投票，确认后查看默契小票。
5. 进入「同城找搭子」查看虚构饭局和筛选效果；这里没有真实在线陌生人，也不会向他人发送报名消息。

演示金额不是官方报价，演示流程不调用真实建单、付款、领券或核销。真实菜单、跨设备餐桌和官方核价的复现步骤见 [README](../README.md) 和 [远程分享说明](REMOTE_SHARING.md)。

## 发布内容与数据边界

| 类型 | 公开版处理方式 |
| --- | --- |
| 应用源码、依赖锁文件、测试和构建配置 | 保留，可复现当前程序 |
| 演示菜单与金额 | 保留 `src/providers/demo.ts` 中明确标注“示例”的虚构数据 |
| 演示成员与饭局 | 保留虚构昵称、预算、偏好和公共商圈示例；不代表真实用户或发布记录 |
| 测试截图 | 只包含 `docs/images/` 下已审阅的测试成员截图，没有有效邀请二维码或支付入口 |
| 测试用身份、Token 字符串和短链接 | 仅保留源码测试中人工构造的无效样例，不带真实账户授权 |
| 个人 MCP Token、密钥、账号、Cookie、会话 | 不随源码提供；新使用者自行连接自己的授权 |
| SQLite 数据库、真实成员、预算、餐品及订单记录 | 不提供开发者的运行数据；新使用者运行后生成自己的本机数据 |
| 个人测试地标与门店 | 从默认搜索和说明中移除；真实点餐页由使用者主动填写城市、地标并搜索 |
| 运行日志、本机报告、原始截图和临时公网地址 | 不进入公开源码或压缩包 |
| 私有仓库 Git 历史 | 不复制到公开仓库 |

网页连接授权后，新用户自己生成的数据仍保存在其运行电脑的 `data/` 和相应浏览器中，按原有程序规则使用。公开版不会提供开发者的授权，也不会修改或删除开发者原电脑的数据库。

## 比赛必需材料

根目录保留 `README.md`、`CONTEST_DECLARATION.md`、`MCP_INTEGRATION.md`、`mcp-config.example.json` 和完整源码。参赛声明保持官方原文，配置示例只使用环境变量占位符。

真实 MCP 验证范围以 [MCP 集成说明](../MCP_INTEGRATION.md) 为准，不能将模拟测试视为完整实单支付验收。没有提供 WorkBuddy 使用记录，也没有代替作者提交报名 Issue。公开发布不等于已通过比赛资格审核。

## 后续更新

开发目录运行 `npm run github:export`，可生成不含运行数据的源码包；导出过程校验必需文件、声明原文和常见凭证模式。发布前仍需检查新增文件、图片和说明，自动扫描不能识别所有敏感信息。

公开仓库的更新应在其独立工作副本中提交。不要将私有仓库的历史直接合并或强推到公开仓库；保留公开历史只包含已检查的源码。第三方许可证继续保留，项目整体授权说明见 [README](../README.md)。
